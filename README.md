Liit Bayebaye 

A modern and responsive web application created to showcase and promote Liit Bayebaye, a local delicacy from Pavia. The platform highlights the product’s cultural roots, brand identity, and local craftsmanship through an engaging and visually appealing user experience.

🚀 Getting Started
Clone the repository
git clone https://github.com/gabwrel/liit-bayebaye.git
Navigate to the project directory
cd liit-bayebaye
Install dependencies
npm install
Run the development server
npm run dev

Open http://localhost:3000 in your browser.
